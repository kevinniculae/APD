# APD – Laborator
Proiect de laborator pentru disciplina Achiziția și prelucrarea datelor.
Nod de achiziție a temperaturii bazat pe Arduino Uno.

## Autor
Niculae-Craciun Alexandru-Kevin - 4LF342

## Hardware
Arduino Uno R3, senzor de temperatură TMP36

Platformă: Arduino Uno R3 (ATmega328P)
Autor laborator: Niculae-Craciun Alexandru-Kevin
## Parametri
- SENSOR_PIN: intrarea analogică a senzorului (A0)
- SAMPLE_PERIOD_MS: perioada de eșantionare, în ms
- SERIAL_BAUD: viteza portului serial
- LED_PIN: pinul LED-ului de stare
- BUTTON_PIN: pinul butonului de pornire/oprire a achiziției
Comunicație serială la 19200 baud
